= 852. 山脉数组的峰顶索引

https://leetcode.cn/problems/peak-index-in-a-mountain-array/[LeetCode - 852. 山脉数组的峰顶索引^]

给定一个长度为 `n` 的整数**山脉**数组 `arr` ，其中的值递增到一个 *峰值元素* 然后递减。

返回峰值元素的下标。

你必须设计并实现时间复杂度为 stem:[O(log(n))] 的解决方案。

*示例 1：*

....
输入：arr = [0,1,0]
输出：1
....

*示例 2：*

....
输入：arr = [0,2,1,0]
输出：1
....

*示例 3：*

....
输入：arr = [0,10,5,2]
输出：1
....

*提示：*

* `3 \<= arr.length \<= 10^5^`
* `0 \<= arr[i] \<= 10^6^`
* 题目数据 *保证* `arr` 是一个山脉数组


== 思路分析

<<0000-03-modified-binary-search>>：中间数跟两边比较，哪边增长，峰值就在哪边，两边都不增长，那么就是峰值。
